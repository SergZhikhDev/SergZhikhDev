# Сергей Жихарев

Основатель **Causa** — командного центра для управления судебными делами для частных лиц и малых юридических фирм. Проект в закрытом репозитории, в активной разработке.

## О проекте

Causa помогает не утонуть в бюрократии: следит за сроками, заседаниями, почтой, исполнительными производствами и связями с контрагентами по множеству дел одновременно. Работает на Google Apps Script и Google Таблицах, ежедневно используется для ведения 12+ реальных судебных дел.

В основе архитектуры — нормализация данных (единая база контрагентов, документов, задач) и разделение хранения: PDF-документы лежат локально на диске пользователя, в облаке — только метаданные и ссылки `file:///`. AI-функции отключены — публичные ИИ-сервисы несовместимы с 152-ФЗ при работе с ПДн клиентов. Вернутся с локальной LLM.

## Чем Causa отличается

- **Локальные документы.** PDF-файлы хранятся на диске, в базе — только ссылки. Конкуренты (Case.one, XSUD, Jeffit) хранят всё в облаке.
- **Аудит связей данных.** Проверка целостности: письма без дел, ИП без дел, дела без УИД. Такого нет ни у кого.
- **Умный подбор дел по контрагенту.** Подсказки в попапах письма и обращения — какие дела связаны с этим контрагентом.
- **Проактивные рекомендации.** Система сама напоминает: «Заседание через 3 дня», «Срок апелляции истекает», «Письмо не вручено 10 дней».
