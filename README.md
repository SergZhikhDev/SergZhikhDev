## О проекте

Causa помогает не утонуть в бюрократии: следит за сроками, заседаниями, письмами и исполнительными производствами по множеству дел одновременно. Работает на Google Apps Script + Google Таблицы, с интеграцией AI-агентов для анализа документов и подготовки позиций.

Проект находится в активной разработке: работающий прототип, ежедневное использование на реальных делах, регулярные обновления.
