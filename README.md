# Сергей Жихарев

Основатель **Causa** — командного центра для управления судебными делами для частных лиц и малых юридических фирм. Проект в закрытом репозитории, в активной разработке.

## О проекте

Causa помогает не утонуть в бюрократии: следит за сроками, заседаниями, почтой, исполнительными производствами и связями с контрагентами по множеству дел одновременно. Работает на Google Apps Script и Google Таблицах, ежедневно используется для ведения 12+ реальных судебных дел.

В основе архитектуры — нормализация данных (единая база контрагентов, документов, задач) и строгий подход к безопасности персональных данных (152-ФЗ).

## Стек

**Работает сейчас:**
- Google Apps Script (бэкенд)
- Google Таблицы (база данных)
- JavaScript, HTML, CSS (фронтенд)
- VS Code + ESLint + Prettier, clasp для синхронизации с Apps Script
- Git + GitHub (версионирование)
- Локальное хранилище файлов (безопасность по 152-ФЗ)

**В планах:**
- Node.js + React + PostgreSQL (промышленный стек для v2.0)
- Локальные LLM (Llama, Saiga) — для конфиденциальной обработки данных. AI-функции Causa временно отключены по 152-ФЗ; вернутся с локальной LLM.
