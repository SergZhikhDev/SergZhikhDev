# Сергей Жихарев

Основатель **[Causa](https://github.com/SergZhikhDev/legal-office-app)** — AI-планировщика судебных дел для частных лиц и малых юридических фирм.

## О проекте

Causa помогает не утонуть в бюрократии: следит за сроками, заседаниями, письмами и исполнительными производствами по множеству дел одновременно. Работает на Google Apps Script + Google Таблицы, с интеграцией AI-агентов для анализа документов и подготовки позиций.

Проект родился из личной практики — веду 12+ судебных дел и знаю цену пропущенному сроку.

## Стек

- **Backend:** Google Apps Script, Node.js (в планах)
- **Frontend:** JavaScript, HTML/CSS, React (в планах)
- **База данных:** Google Таблицы, PostgreSQL (в планах)
- **AI:** DeepSeek, локальные LLM (в разработке)
- **Инструменты:** Git, clasp, VS Code
